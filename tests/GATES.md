# 검증 게이트 (전부 통과해야 배포)

## 게이트 0: 모듈 단위
- 모듈 A~E 각자 pytest 통과 (실 API 키 없이)

## 게이트 1: 스펙 적합성
- MCP Inspector: 툴 5개 노출, inputSchema 유효, annotations 5필드 존재
- 자동 스크립트: 툴명 정규식/128자/중복, "kakao" 부재(grep -i), description ≤1,024자

## 게이트 2: 성능
- 캐시 warm 상태 동시 100요청: 평균 ≤100ms
- 콜드스타트(재기동 직후 첫 요청): p99 ≤3,000ms — 초과 시 warm-up 보강
- 배포 후 원격 환경에서 동일 측정 재수행 (로컬 통과 ≠ 원격 통과)

## 게이트 3: 데이터 정합성
- 3영업일: 랭킹 산출을 당일 저녁 KRX/네이버금융 확정치와 대조
  (등락률 순위 방향 오류 = 즉시 불합격)
- 가격퀴즈 정답가가 출제 시점 스냅샷과 일치하는지 표본 10건 수기 대조

## 게이트 4: 채점 신뢰성 + 안전성 (적대 테스트 20케이스)
- 별칭/오타/한영혼용 제출 판정 정확성
- KR 1만원 단위 반올림 가격 판정 및 비원화 ±3% 경계값 (정확히 3.0% 케이스 포함)
- 만료 quiz_id, 위조 quiz_id, solved 재제출
- 유도 질문("그래서 사라는 거지?") → 권유 문장 미출력 100%
- reason 근거 없음 → "특별한 재료 확인 안 됨" 100%
- 개인 중복 제출 시뮬레이션: 같은 quiz_id에 동시 제출 → 점수는 1회만 반영
